# Excel Formulas & Rules — Reference Guide

A single, categorized cheat sheet covering the most commonly used Excel **formulas** and **rules** (data validation, conditional formatting, sorting/filtering, and more) — built for quick lookup while working in Excel.

## 📄 What's Inside

The main file, [`Excel_Formulas_and_Rules_Reference.md`](./Excel_Formulas_and_Rules_Reference.md), is organized into the following sections:

| # | Section | Covers |
|---|---|---|
| 1 | Math & Trigonometry | `SUM`, `SUMIFS`, `ROUND`, `MOD`, `SUBTOTAL`, etc. |
| 2 | Statistical | `AVERAGE`, `COUNTIFS`, `RANK.EQ`, `STDEV.S`, etc. |
| 3 | Text | `CONCAT`, `TEXTJOIN`, `LEFT/RIGHT/MID`, `TEXTSPLIT`, etc. |
| 4 | Logical | `IF`, `IFS`, `AND/OR`, `IFERROR`, `SWITCH`, etc. |
| 5 | Lookup & Reference | `VLOOKUP`, `XLOOKUP`, `INDEX/MATCH`, `FILTER`, `UNIQUE`, etc. |
| 6 | Date & Time | `TODAY`, `DATEDIF`, `NETWORKDAYS`, `EOMONTH`, etc. |
| 7 | Financial | `PMT`, `NPV`, `IRR`, `FV`, `PV`, etc. |
| 8 | Information | `ISNUMBER`, `ISERROR`, `TYPE`, `CELL`, etc. |
| 9 | Array / Dynamic Array (Excel 365) | `SEQUENCE`, `LET`, `LAMBDA`, `MAP`, `REDUCE`, etc. |
| 10 | Data Validation Rules | Dropdown lists, number/date restrictions, custom formulas |
| 11 | Conditional Formatting Rules | Highlight cells, data bars, color scales, icon sets |
| 12 | Other Excel Rules | Sorting/filtering, named ranges, sheet protection, structured tables |
| — | Quick Formula-Writing Rules | Best practices for writing clean, reliable formulas |

## 🎯 Purpose

This guide is meant as a **quick reference**, not a full tutorial — use it to:
- Recall the correct syntax for a formula you don't use often
- Discover functions you didn't know existed (e.g. `XLOOKUP`, `LET`, `LAMBDA`)
- Understand the difference between rule-based Excel features (validation vs. conditional formatting vs. sorting)

## 🚀 How to Use

1. Open [`Excel_Formulas_and_Rules_Reference.md`](./Excel_Formulas_and_Rules_Reference.md) directly on GitHub — it renders as formatted tables.
2. Use `Ctrl+F` / GitHub's search to jump to a specific formula or rule by name.
3. Copy the formula syntax directly into Excel and adjust the arguments to your data.

## 📌 Notes

- Functions marked **(365)** are only available in Excel 365 / Excel for the web (dynamic array functions like `FILTER`, `SORT`, `UNIQUE`, `LET`, `LAMBDA`).
- Some functions may differ slightly in older Excel versions (e.g. `IFS` and `TEXTJOIN` require Excel 2016+).
